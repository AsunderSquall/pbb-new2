# 多字符集格式

`character_sets` 是名字到字符集配置的字典，每族沿用原 `character_set` 的字段。
`format` 是按顺序拼接的列表：字符串表示固定内容，`{charset: 族名}` 表示一个可变位置。
引用相同族多次仍是独立位置。字符串即使等于族名，也保持固定内容。

```yaml
character_sets:
  数字: {single_char_length: 1, types: [1]}
  汉字: {single_char_length: 3, types: [7], custom_values: 春夏秋冬}
format: ["编号", {charset: 汉字}, "-", {charset: 数字}, {charset: 数字}]
```

每族内部的枚举单元必须是相同**字节长度**，不同族可以不同宽度。
6 字节词条仍按每 6 字节切分。族内不自动去重，候选顺序沿用字符集构建顺序。
至少一个可变位置，完整名字加前后缀少于 512 字节，不能含 NUL。

完整名字是 `prefix + format + suffix`。前后缀可省略，默认各一个空串；显式前后缀沿用当前配对、随机选择和按前缀区间规则。
`enumeration.variable_length` 在格式模式下自动取可变位置数。
旧 `character_set` 加 `variable_length` 配置完全沿用原路径；同时有 `format` 时使用新格式。

- mode 1：右端位置先变化的混合进制枚举，范围按各位置字符数的乘积截断。`end: -1` 表示枚举全部可表示候选。
- mode 2/4：从右侧选取乘积至少一百万的低位位置，其余高位每 chunk 随机一次，低位选随机起点后顺序进位一百万次。低位耗尽时回绕，候选可重复；mode 4 继续配对前后缀。
- mode 3：同样区分高低位，高位每 chunk 随机一次，低位逐候选随机，不保证去重；尾 chunk 只处理请求数量。

随机流仍由现有 chunk 种子驱动。新格式采用上述混合进制语义，旧配置的随机结果不变。
评分、门控、潜力、技能、收集、普通输出、UI Top 与动态线程控制复用当前引擎。
顺序格式任务在 `out/<结果文件>.resume` 写入各前缀的连续完成检查点。
多线程乱序完成时，只推进连续完成的区间；尾批和没有评分命中的任务也可恢复。
停止或进程被终止后，未完成的块重新计算，可能重复输出，但不会从最后一条命中推断并跳过未完成候选。
重复条目、重叠前缀和固定空格无需反向解析名字。旧配置继续使用原来的命中反推续测。
格式任务没有检查点时从配置起点重测。检查点校验实际字符集顺序、格式、前后缀、队伍、评分和收集配置；不一致会拒绝续测。
保留结果文件与 `.resume` 文件一起迁移。可缩小检查点覆盖的范围；扩大范围需要新的结果文件。
输出规则身份包含当前QP二次扣分版本；旧QP−PP或幻影硬过滤规则的检查点不能与当前结果混用，需换用新的结果文件并从配置起点测。
UI 的自动更新起点也按各前缀检查点更新，不再用所有线程的处理量累加到单一起点。

## 从文件导入

```yaml
character_sets:
  词语: {single_char_length: 6, file: words.txt, file_format: lines}
format: ["编号", {charset: 词语}]
```

文件为 UTF-8（可带 BOM）。默认 `lines`：每行一个枚举单元，适合词语；行内空格保留，空行报错，末尾换行可省略。
`text`：逐 Unicode 字符导入，忽略 CR/LF，其他空格保留。每个单元的 UTF-8 字节数必须等于 `single_char_length`。
保留文件顺序和重复条目，不能同时指定 `types/custom_values/unicode_ranges`。
相对路径相对于配置文件所在目录；加载后保存为绝对路径，移动到别的机器时需修改路径。
启动时将文件内容固定为本次任务字符表；下次续测若文件内容或顺序变化会拒绝使用旧检查点。

UI 配置编辑器的“多字符集格式”页可启用格式、编辑族字典与格式列表（JSON）。
页内两个导入按钮分别支持每行一个单元、逐字符；选择文本文件后自动推断字节宽度，再输入新的族名，随后在格式列表中引用该名字。
基础页的单字符集与变量长度用于旧配置；启用格式时以新页为准。
族字典与列表可保存为 YAML、JSON 或 TOML，配置选择器显示各族宽度和大小。

示例：`python main.py -c config/config_flex.example.yaml`；重建仍使用 `python tools/rebuild_local.py`。
续测身份包含生产门控版本；QP二次扣分启用后，旧 QP−PP 或幻影硬门控生成的检查点不再兼容，应使用新的结果文件启动任务。
`--vlen/--scl/--types/--custom-values` 不用于格式模式，请直接编辑对应族和格式。
